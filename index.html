Структура документа

  • "!DOCTYPE html" Вказує тип документа (HTML 5)
  • "html" Кореневий елемент HTML-документа
  • "head" Метаінформація (назва, стилі, скрипти)
  • "body" Основний вміст сторінки
  • "title" Назва сторінки (у вкладці браузера, прописується всередині title)
  • "link" Під'єднує зовнішні файли
  • "script" Вбудований JacaScript
  • "style" Вбудовані стилі CSS

Текст та форматування

  • "h1-h6" Заголовки (від меншого до більшого)
  • "p" Абзац
  • "br" Перенесення рядка
  • "hr" Горизонтальна лінія
  • "strong" Виділення тексту жирним шрифтом
  • "b" Жирний текст
  • "em" Наголос
  • "i" Курсив
  • "u" Підкреслення
  • "small" Менший текст
  • "mark" Підсвічування тексту
  • "sup/sub" Верхній/нижній індекс
  • "pre" Збереження форматування пробілів
  • "blockquote" Цитата
  • "q" Коротка цитата в рядку
  • "abbr" Скорочення з підказкою (title)
  • "code" Фрагмент коду
  • "span" Вбудований контейнер для стилізації тексту
  • "div" Блоковий контейнер

Списки

  • "ul" Маркований список
  • "ol" Нумерований список
  • "li" Елемент списку (задається після визначення типу списку)
  • "dl" Список визначень
  • "dt" Термін
  • "dd" Опис терміну

Посилання та мультимедіа

  • "a" Гіперпосилання
  • "img" Зображення
  • "figure" Блок зображення або діаграма
  • "figcaption" Підпис до зображення
  • "audio" Відтворення звуку
  • "video" Відтворення відео
  • "source(src)" Джерело для audio, video
  • "iframe" Вбудування іншої сторінки (наприклад YouTube)

Таблиці

  • "table" Таблиця
  • "tr" Рядок таблиці
  • "th" Заголовок стовпця
  • "td" Комірка таблиці
  • "thead" Верхня частина таблиці
  • "tbody" Основна частина таблиці
  • "tfoot" Нижня частина таблиці
  • "caption" Назва таблиці

Форми

  • "form" Форма для введення даних (по типу head)
  • "input" Поле введення
  • "textarea" Багаторядкове поле введення
  • "label" Підпис для поля
  • "select" Випадаючий список
  • "option" Елемент списку
  • "button" Кнопка
  • "fieldset" Групування елементів форми
  • "legend" Заголовок групи
  • "output" Результат обчислення
  • "datalist" Підказки для input
  • "meter" Вимірювальний індикатор
  • "progress" індикатор виконання

Семантична розмітка

  • "header" Верхня частина сторінки або секції
  • "nav" Меню навігації
  • "main" Основний контент
  • "section" Розділ сторінки
  • "article" Самостійник блок(стаття, пост)
  • "aside" Бокова панель
  • "footer" Нижня частина сторінки
  • "details" Прихований контент, що розкривається
  • "summary" Заголовок для details
  • "dialog" Діалогове вікно

Інше

  • "canvas" Область для малювання (через JS).
  • "svg" Векторна графіка.
  • "noscript" Текст, якщо JS вимкнено.
  • "template" Шаблон, який не відображається одразу.
  • "slot" Місце вставки контенту у Web Components.

Основи CSS

  • "color" Колір тексту.
  • "background-color" Колір фону.
  • "background-image" Фонове зображення.
  • "background-repeat" Повторення фону (repeat, no-repeat).
  • "background-size" Розмір фону (cover, contain, тощо).
  • "background-position" Позиція фону (center, top, left).
  • "opacity" Прозорість елемента (0–1).
  • "visibility" Видимість (visible, hidden).
  • "cursor" Вид курсора при наведенні.

Розмітка та блоки

  • "width / height" Ширина / висота елемента.
  • "max-width / min-width" Максимальна / мінімальна ширина.
  • "margin" Зовнішні відступи.
  • "padding" Внутрішні відступи.
  • "border" Рамка навколо елемента.
  • "border-radius" Закруглення кутів.
  • "box-sizing" Врахування padding/border у розмірах (content-box, border-box).
  • "overflow" Поведінка при переповненні (hidden, scroll, auto).
  • "display" Тип відображення (block, inline, flex, grid, none).
  • "position"Позиціонування (static, relative, absolute, fixed, sticky).
  • "top, right, bottom, left" Відстань від країв при позиціонуванні.
  • "z-index" Шар (глибина) елемента.

Текст і шрифт

  • "font-family" Назва шрифту.
  • "font-size" Розмір шрифту.
  • "font-weight" Товщина (normal, bold, 100–900).
  • "font-style" Стиль (normal, italic).
  • "text-align" Вирівнювання тексту (left, center, right).
  • "text-decoration" Підкреслення, закреслення тощо.
  • "text-transform" Зміна регістру (uppercase, lowercase).
  • "line-height" Висота рядка.
  • "letter-spacing" Відстань між літерами.
  • "word-spacing" Відстань між словами.
  • "white-space" Поведінка пробілів і переносів.
  • "text-shadow" Тінь тексту.

Кольори та ефекти

  • "box-shadow" Тінь для блоку.
  • "filter" Фільтри (blur, brightness, grayscale, тощо).
  • "mix-blend-mode" Змішування кольорів.
  • "background-blend-mode" Змішування фону.

Flexbox (гнучке вирівнювання)

  • "display: flex" Включає режим flex.
  • "flex-direction" Напрямок (row, column).
  • "justify-content" Вирівнювання по осі X.
  • "align-items" Вирівнювання по осі Y.
  • "align-content" Вирівнювання рядків усередині контейнера.
  • "flex-wrap" Перенесення елементів (wrap).
  • "gap" Відстань між елементами.
  • "flex-grow" Розтягування елемента.
  • "flex-shrink" Стискання елемента.
  • "flex-basis" Початковий розмір.
  • "order" Порядок елементів.

Grid (вирівнювання за сіткою)

  • "display: grid" Включає сітку.
  • "grid-template-columns" Кількість і розміри стовпців.
  • "grid-template-rows" Кількість і розміри рядків.
  • "grid-gap / gap" Відстань між елементами.
  • "grid-column / grid-row" Позиціонування в сітці.
  • "justify-items / align-items" Вирівнювання всередині комірки.
  • "justify-content / align-content" Вирівнювання всієї сітки.

Анімації та переходи

  • "transition" Плавна зміна властивостей.
  • "transition-duration"Тривалість переходу.
  • "transition-property" Що змінюється.
  • "animation" Анімація за ключовими кадрами.
  • "@keyframes" Опис руху (ключові кадри).
  • "animation-name, animation-duration, animation-iteration-count" Параметри анімації.

Адаптивність

  • "@media" Правила для певних екранів (наприклад, мобільних).
  • "max-width, min-width" Використовуються в медіа-запитах.
  • "vw, vh, %, px" Відносні одиниці для розмірів.

Інше

  • "content" Вміст для псевдоелементів (::before, ::after).
  • "clip-path" Обрізання форми елемента.
  • "pointer-events" Вплив на кліки.
  • "user-select" Заборона виділення тексту.
  • "transform" Перетворення (rotate, scale, translate).
  • "perspective" Глибина 3D.

Базові елементи

  • "//"" Однорядковий коментар.
  • "/* ... */" Багаторядковий коментар.
  • "let" Змінна, яку можна змінювати.
  • "const" Константа (не змінюється).
  • "var" Старий спосіб оголошення змінних.
  • "typeof" Повертає тип значення.
  • "null" Порожнє значення.
  • "undefined" Невизначене значення.
  • "NaN" - “Не число” (результат помилки обчислення).

Типи даних

  • "Number" - 42, 3.14 - Числа.
  • "String" - "Привіт" - Рядки.
  • "Boolean" - true, false - Логічні значення.
  • "Array" - [1, 2, 3] - Масив значень.
  • "Object" - {name: "Іван", age: 18} - Об’єкт (набір пар “ключ–значення”).
  • "Function" - function hello(){} - Функція.
  • "Symbol" - Symbol('id') - Унікальний ідентифікатор.
  • "BigInt" - 123n - Дуже велике число.

Оператори

  • "Арифметичні" +, -, *, /, %, ** Дії з числами.
  • "Порівняння" ==, ===, !=, >, <, >=, <= Порівняння значень.
  • "Присвоєння" =, +=, -=, *=, /= Зміна змінної.
  • "Тернарний" умова ? якщо_так : якщо_ні Короткий if.
  • "Конкатенація" "a" + "b" Об’єднання рядків.

Умови та цикли

  • "if, else if, else" Виконання коду за умовою.
  • "switch" Вибір з кількох варіантів.
  • "for" Цикл з лічильником.
  • "while" Цикл, поки умова істинна.
  • "do...while" Виконується хоча б раз.
  • "break" Зупиняє цикл.
  • "continue" Пропускає одну ітерацію.

Функції

  • "function name(){}" Оголошення функції.
  • "return" Повертає результат.
  • "() => {}" Стрілочна функція.
  • "arguments" Доступ до переданих параметрів.
  • "...args" Решта аргументів (rest-parameter).
  • "call(), apply(), bind()" Керування контекстом (this).

Масиви

  • "push() / pop()" Додати / видалити з кінця.
  • "shift() / unshift()" Видалити / додати на початку.
  • "slice()" Витягти частину масиву.
  • "splice()" Додати / видалити елементи.
  • "forEach()" Перебір елементів.
  • "map()" Перетворити кожен елемент.
  • "filter() Вибрати елементи за умовою.
  • "reduce() Підсумувати або об’єднати.
  • "find() / findIndex() Знайти елемент або його індекс.
  • "includes() Перевірити наявність елемента.
  • "sort() Сортування.
  • "reverse() Зворотний порядок.

Об’єкти

  • "obj.key або obj["key"]" Доступ до властивості.
  • "Object.keys()" Список ключів.
  • "Object.values()" Список значень.
  • "Object.entries()" Пари ключ–значення.
  • "delete obj.key" Видалити властивість.
  • "this" Посилання на поточний об’єкт.

DOM (взаємодія з HTML)

  • "document.getElementById()" Знайти елемент за id.
  • "document.querySelector()" Знайти елемент за CSS-селектором.
  • "innerHTML / textContent" Змінити вміст.
  • "style.property" Змінити стиль.
  • "setAttribute() / getAttribute()" Робота з атрибутами.
  • "classList.add() / remove()" Робота з класами.
  • "createElement()" Створити елемент.
  • "append() / prepend() / remove()" Додавання або видалення елементів.

Події

  • "onclick, oninput, onchange, onmouseover" Події взаємодії користувача.
  • "addEventListener()" Додати обробник події.
  • "removeEventListener()" Видалити обробник.
  • "event.target" Елемент, що викликав подію.
  • "preventDefault()" Скасувати стандартну дію.

Час та асинхронність

  • "setTimeout()" Виконати код із затримкою.
  • "setInterval()" Виконувати код регулярно.
  • "clearTimeout() / clearInterval()" Зупинити таймер.
  • "Promise" Асинхронна операція.
  • "async / await" Зручний синтаксис для Promise.
  • "fetch()" HTTP-запит до сервера.
  • "then() / catch() / finally()" Обробка результату промісу.

Локальне зберігання

  • "localStorage" Постійне зберігання у браузері.
  • "sessionStorage" Тимчасове (до закриття вкладки).
  • "localStorage.setItem('key', 'value')" Зберегти дані.
  • "localStorage.getItem('key')" Отримати дані.
  • "localStorage.removeItem('key')" Видалити.

Інше

  • "JSON.stringify() / JSON.parse()" Перетворення об’єкта ↔ текст JSON.
  • "Math.random()" Випадкове число.
  • "Math.floor() / ceil() / round()" Округлення.
  • "Date()" Поточна дата й час.
  • "alert() / prompt() / confirm()" Діалогові вікна.
  • "try...catch" Обробка помилок.
  • "throw" Виклик помилки вручну.
  • "import / export" Імпорт або експорт модулів.
